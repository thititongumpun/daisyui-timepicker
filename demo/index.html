Install 
npm install daisyui-timepicker daisyui tailwindcss

One line of CSS, or it renders as plain text.

Tailwind does not scan node_modules. Leave this line out of your CSS and the picker renders as unstyled stacked text — no console error, no build warning, no failing check. It is the single most expensive thing to get wrong here, so it sits above the examples rather than below them.

Required in your own CSS
app.css 
@source "../node_modules/daisyui-timepicker/dist";

The path is relative to your CSS file. On Tailwind v3, add the same path to the content array instead. This demo does the same thing one directory up — demo/app.css carries @source "../dist", and deleting it strips every class off the pickers below.

Three ways to mount it.

Copied verbatim from the README, so these cannot drift from the documented API.

Plain HTML 
<script type="module" src="node_modules/daisyui-timepicker/dist/index.js"></script>

<label for="meeting-time" class="label">Meeting time</label>
<daisy-time-picker
  id="meeting-time"
  name="time"
  hour-cycle="24"
  min="09:00"
  max="18:00"
  step="900"
></daisy-time-picker>

<script type="module">
  const picker = document.getElementById('meeting-time')
  picker.addEventListener('change', e => console.log(e.target.value)) // "HH:MM"
</script>
Preact 
import 'daisyui-timepicker'
import 'daisyui-timepicker/preact' // JSX types only, zero runtime bytes
import { useState } from 'preact/hooks'

function Meeting() {
  const [time, setTime] = useState('09:00')
  return (
    <daisy-time-picker
      value={time}
      hour-cycle="24"
      onChange={e => setTime(e.target.value)}
    />
  )
}

Preact wires onChange straight to the element’s native change event, so no ref is needed.

React 19 / Next.js 
'use client'
import 'daisyui-timepicker'
import 'daisyui-timepicker/react' // JSX types only, zero runtime bytes
import { useEffect, useRef, useState } from 'react'

function Meeting() {
  const ref = useRef(null)
  const [time, setTime] = useState('09:00')

  useEffect(() => {
    const el = ref.current
    const h = e => setTime(e.target.value)
    el.addEventListener('change', h)
    return () => el.removeEventListener('change', h)
  }, [])

  return <daisy-time-picker ref={ref} value={time} hour-cycle="24" />
}

React does not wire onChange to a custom element’s change event. React 19 sets properties on custom elements directly, but its ChangeEventPlugin only fires synthetic onChange for real <input>, <select> and <textarea> — never for a custom element. The React types in this package deliberately omit onChange and onInput rather than advertise a handler that silently never fires, so a ref is required. React 18 and earlier are not supported.

Reference, condensed.

The parts you reach for first. Every attribute has a matching property, and the full reference in the README carries the rest — defaultValue, resolvedHourCycle, the ElementInternals delegates, and the hour-cycle="auto" detection rules.

Attributes

AttributeDefaultWhat it does
value''"HH:MM", always 24-hour storage. Never reflected back to the attribute.
hour-cyclenull"12" or "24" pins the format. Anything else auto-detects from Intl.
min / maxnull"HH:MM". min > max is an overnight wrap.
step60Seconds, like native <input type="time">. Filters options; never rounds the value.
requiredfalseSets valueMissing while empty.
disabledfalseAlso honoured from an ancestor <fieldset disabled>.
namenullForm field name, submitted through ElementInternals.
labelnullSets aria-label on the internal input.

Events

EventFiresRead
inputEvery committed change while the panel is open — arrows, click, Now, parsed typing.e.target.value
changeOn close, when the value moved since focus or open.e.target.value

Both are plain Event objects, not CustomEvent — read e.target.value, never e.detail.

Keyboard

KeyWhereAction
Enter / ↓Trigger inputCommits typed text, opens the panel, focuses the hour column.
EscAnywhere openRestores the value it had when the panel opened, silently, and closes.
← / →A columnMoves between Hour, Minute and AM/PM.
↑ / ↓A columnMoves and commits one enabled option.
PgUp / PgDnA columnMoves and commits ten enabled options.
Home / EndA columnJumps to the first or last enabled option.
Enter / SpaceA columnCloses the panel; the value is already committed.

Disabled out-of-range options are skipped by all of the above. Focus stays on the listbox container the whole time via roving aria-activedescendant.
